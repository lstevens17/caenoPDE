# Code and plots associated with "Programmed DNA elimination was present in the last common ancestor of Caenorhabditis nematodes"

## [1_discovery](https://github.com/lstevens17/caenoPDE/tree/main/1_discovery)
Code and files related to the "Programmed DNA elimination in three Caenorhabditis species" results section.

## [2_motif](https://github.com/lstevens17/caenoPDE/tree/main/2_motif)
Code and files related to the "Sequence motifs at telomere addition sites" results section. 

## [3_contents](https://github.com/lstevens17/caenoPDE/tree/main/3_contents)
Code and files related to the "A subset of eliminated genes have known germline functions in C. elegans" and "Satellite repeats and helitrons are common in eliminated DNA" results sections.

## [5_rearrangement](https://github.com/lstevens17/caenoPDE/tree/main/5_rearrangement)
Code and files related to the "Some elimination sites are orthologous and some coincide with rearrangement sites" results section.

## [6_evolution](https://github.com/lstevens17/caenoPDE/tree/main/6_evolution) 
Code and files related to the "PDE is absent in other Caenorhabditis species" results section. 

## [eliminated_bed_files](https://github.com/lstevens17/caenoPDE/tree/main/eliminated_bed_files)
BED files containing coordinates for eliminated regions in the genomes of all three species. 

## [gene_annotation_files](https://github.com/lstevens17/caenoPDE/tree/main/gene_annotation_files)
GFF3, protein, and CDS files for all protein-coding annotations generated as part of the manuscript.
